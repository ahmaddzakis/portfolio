## 📖 Tentang Proyek

Website portofolio personal milik **Ahmad Dzaki**, mahasiswa Teknik Informatika semester 6 di Universitas Pasundan. Portofolio ini menampilkan karya-karya di bidang **UI/UX Design**, **Flutter Development**, dan **Game Design** dengan desain dark-mode modern bertema budaya Sunda (motif Batik Mega Mendung Cirebon).

Situs ini dibangun dengan performa tinggi, aksesibilitas penuh, dan SEO teroptimasi — dengan dukungan bilingual **Bahasa Indonesia / English**.

## 🗂️ Struktur Proyek

```
portfolio/
├── index.html              # Halaman utama (single-page)
├── 404.html                # Halaman error kustom
├── sitemap.xml             # Sitemap untuk SEO
├── tailwind.config.js      # Konfigurasi Tailwind CSS
├── package.json            # Dependensi Node.js
│
└── assets/
    ├── css/
    │   ├── input.css       # Source Tailwind CSS
    │   ├── output.css      # Compiled & minified CSS
    │   └── style.css       # Custom styles tambahan
    ├── js/
    │   └── script.js       # JavaScript utama (navbar, slider, dll.)
    ├── images/
    │   ├── profile.png     # Foto profil

    │   ├── batik/          # Aset motif Mega Mendung
    │   └── projects/       # Screenshot proyek (MIRAIku, SLIDER)
    └── docs/               # Dokumen CV
```

## 🚀 Cara Menjalankan Lokal

### Prasyarat
- [Node.js](https://nodejs.org/) v16+
- npm

### Langkah Instalasi

```bash
# 1. Clone repositori ini
git clone https://github.com/ahmaddzakis/portfolio_dzaki.git

# 2. Masuk ke direktori proyek
cd portfolio_dzaki

# 3. Install dependensi
npm install
```

### Build CSS

```bash
# Compile Tailwind CSS (minified untuk produksi)
npm run build
```

### Menjalankan Secara Lokal

Karena ini adalah proyek HTML statis, Anda bisa membukanya langsung di browser atau menggunakan extension **Live Server** di VS Code untuk hot-reload.
